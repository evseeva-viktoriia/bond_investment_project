# School Bond Investment Project

Load data from iss.moex (prices, coupons, amortizations)
Calculate bond horizon yields for multiple horizon periods.

Use libraries:
* httpx to get data from iss.moex.com
* polars to manipulate dataframes
* pydantic for data models
* xlsxwriter to write report to excel
